# FrameRecorder 1.0.0 / ModLoader 2.5.0 本机验证

用户目标：正常游玩时低开销记录帧率和场景，为 agent 定位卡顿发生的时间、地点及相关状态；不把记录器变成新的卡顿来源。基于连续 ENTER_FRAME 到达计时，避免 EXIT_FRAME 重复派发、截图/外部高频监控干扰。复用共享知识 KB-000107、KB-000056 的测量边界，不修改随机数、世界或玩家输入。

## 过程中的失败与修正

1. 摘要初测6/8：Windows 对接近1970的本地时间转换报错；改用 UTC aware 转换后8/8通过。
2. 构建调用旧 PowerShell 缺 Get-FileHash；改用已探测的捆绑 PowerShell 7。编译产物不直接放入正式 release。
3. 首次沙箱 CreateDesktop 被拒绝；未启动游戏，改用正常权限运行相同的自有隔离桌面，不回退前台、不改 AIR 标识或 DLL。
4. 登记遇到 SQLite 锁超时、阅读表被 Windows 读取句柄占用。数据库等锁改60秒；Markdown 替换失败仅提示，不使有效登记回滚，不放行第二个游戏测试。模拟占用回归通过。中途一次重复 finally 编辑造成语法错误，已立即撤销并通过 py_compile；不保留在最终源码。
5. 原登记并发/崩溃夹具依赖10秒启动和8秒子进程寿命，当前环境出现超时；改用最长60秒启动等待、显式文件释放子进程，仍断言子进程活着时不能恢复占用，最终10/10通过。
6. `20261024-104719-1ede7e99/smoke-stall` 三模块 loader OK，但停在 boot，外部106秒看门狗终止自己的进程，没有探针结果。判无效，不进入性能统计。补启动阶段状态日志并将验证驱动启动余量增至240秒；采样阶段不写这些阶段日志。
7. `20261024-110610-f0a6d4cc` 游戏新档有效，但首批记录工作达54 ms，自动停用，未部署。分段测量 `20261024-111244-e2c4f5b8` 再次观察 I/O 阶段38 ms，JSON最多1 ms、摘要0 ms（低于毫秒计时精度）；不能把异步 API 名称视为主线程零耗时。改为加载期只打开一次持久异步流，运行中在同一固定文件循环写入；未引入额外 Worker 虚拟机。
8. 常驻文件候选 `20261024-112031-dc1746b5`：新档长帧含位置、禁用、两轮开启、目录失败及坏配置断言通过。观测记录工作峰值2/2/11 ms；独立进程 ABBA mean 差约+0.611 ms、P95差+2.5 ms，未满足预定尾延迟门槛，不能声称零开销。soak 又在菜单资源尚未加载完成时内部60秒超时，未进入长时采样。仍未部署。
9. 后续验证采用同进程两组ABBA（各块5秒缓冲＋20秒测量）减少启动/进程差异；门槛预先设为 mean 增量<0.5 ms、P95增量≤2 ms，之后连续开启至少5分钟核验轮换。测试专用驱动使用独立桌面内正常窗口及180秒启动余量；这不是对早先超时原因的定论。补充注入长帧的 getTimer 起止证据，按同一时钟核对记录时刻。


10. 持久流 `20261024-114109-3e7e96e9` 精确匹配180 ms注入的结束计时与房间/坐标；同进程8块对照 mean +0.580 ms、P95 +0.5 ms，mean 未达门槛。长时采样被累计预算停用；改为60秒滚动预算并保留首个原因。
11. 后续持久流 `20261024-115527-cc576c9b` 仍出现 I/O 观测37 ms，主动停用，未部署。两次文件共享读取（含正常Windows权限）确认运行中独占文件，读端得不到实时日志。
12. 据此放弃游玩期间文件写入，改为300窗内存环，正常退出同步导出；无需Worker或额外常驻进程。实测补充窗口 close 事件与驱动显式保存；保存失败仍允许正常退出。最终验证沿用相同 ABBA 门槛，不把旧失败候选当作成功证据。

13. 纯内存首轮新档正常，但仅监听 closing/exiting 未保存直接 exit 的记录，未部署。补 close 事件和探针退出前显式保存后，20261024-122349-72b55cf0 关窗保存通过，14窗、游玩写盘0、退出保存211 ms；最终全套验证另列。

## 安全边界

测试均用启动器精确选择、独立副本/唯一 AIR ID、独立 Windows 桌面、共享 game 占用；不读写真实玩家存档或更改正式选择。正式运行只写自己的诊断目录。最终候选改为固定300窗内存环；正常退出导出单份最大3.84 MB，临时文件另占最多3.84 MB。游戏中无序列化或文件写入，强退/崩溃无法保存本轮记录。超预算是事后退让，不能保证绝对零开销。后台菜单/新档不等于前台复杂战斗或14模组组合认证。
